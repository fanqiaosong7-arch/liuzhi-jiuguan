# 柳枝酒馆 · Web 像素版（web/）

> 终端版（`main.py`）的浏览器移植：像素风小游戏，**零依赖、多文件、纯原生 JS**。
> 规则与终端版完全一致（统一钱包/防刷条款/作弊码），数据存于浏览器 localStorage。

## 📦 给玩家分发

两种形式任选：

| 形式 | 文件 | 玩法 |
|---|---|---|
| **单文件版（推荐）** | 项目根的 `柳枝酒馆-网页版-单文件.html`（~287KB，版本 2026-08-15 16:12） | 直接双击打开，一个文件走天下，微信/邮件/U盘直传 |
| **目录版** | `web/` 整个目录（zip 见项目根 `柳枝酒馆-网页版.zip`） | 解压后双击 `web/index.html` |

> 单文件版由 `web/build_single.py` 从多文件版生成；改过 `web/js/*` 或 `css` 后记得重新运行：
> `python3 web/build_single.py`（脚本会校验版本号与源码修改时间，防止"改了半天玩的是旧版"）

**🌐 在线版（官方永久链接）**：**https://liuzhi-jiuguan.netlify.app**
- 已部署上线（HTTP 200，与本地单文件字节级一致），电脑关机也能玩，发给任何人即可玩
- 更新流程：把最新单文件复制为 `site/index.html` 后执行 `netlify deploy --dir=site --prod`（模板见 `新手礼包/deploy.sh`），网址不变；更新后建议强刷（Ctrl+F5）避免旧缓存
- ⚠️ **存档存在浏览器 localStorage，按网址隔离**：让玩家固定用一个链接，换网址/换浏览器/清缓存存档不互通（游戏内床头柜有存档导出/导入可迁移）

## 📱 手机上玩

- 打开方式：把 `柳枝酒馆-网页版-单文件.html`（或 zip 解压后的 `index.html`）发给手机，用浏览器打开即可（微信里可直接用"浏览器打开"，或存到手机后用任意浏览器打开）
- **触摸操作**（触屏设备自动显示虚拟按键）：
  - 左下角 **十字方向键**：按住移动角色（可多指同时按）
  - 右下角 **✋ 交互**：相当于键盘 E（靠近床/牌桌/门时按它）
  - 右下角 **☰ 菜单**：相当于 Esc（暂停/退出酒馆）
- 游戏内全部用**点击按钮**操作，下注框弹出数字键盘输入
- 竖屏/横屏都能玩（横屏画面更大）；建议在浏览器里"添加到主屏幕"全屏体验
- ⚠ 存档存在浏览器 localStorage：换浏览器/清缓存会重置钱包；无痕模式刷新后可能不保留

## 🎮 玩法

- **出生点**：每次进入酒馆，你都在**二楼自己的小房间**里醒来（早晨）。
  - 🛏 **床**：睡觉 → 醒来是第二天早晨（跳过剩余时间段，心情 +15）
  - 🗄 **床头柜**：打开钱包（余额/流水/难度/时间/心情）
  - 📅 **日历**（墙上）：柳溪历日期/星期 + 今日时间段进度
  - 🚪 **门**：下楼去大厅
- **时间系统**：一天 = 早晨 → 中午 → 晚上
  - 每"进出"一次大厅游戏（进游戏再退出回大厅）：早晨 5 次 → 中午，再 5 次 → 晚上
  - 入夜后最多再进出 2 次，主角**自动回房睡觉**（醒来是第二天早晨）
  - 窗口的景色和 NPC 闲谈会随时段变化
- **心情系统**：赢钱↑ 输钱↓ 喝酒吃小吃↑ 睡好觉↑ 买家具↑（0~100，HUD 显示表情）
- **日赢钱上限**：**已开放为无限**（`DAILY_WIN_CAP_ENABLED` 开关，代码里可随时恢复老板 $20 / NPC $8）
- **赊账与经济**（$50 在当地是巨款，一年收入水平）：
  - 钱包最多欠到 **-$30**（老板的赊账上限）；达到后**老板不再赊账**，不能进赌局
  - 解法一：找商人 **💰 贷款**（$10/$20/$50，**日息 5%**，睡一觉滚一次利息）
  - 解法二：等**奶奶的零花钱**——每 3 天捎来 **$7**
  - 下注受赊账额度约束，且**不能超过对手的钱包**：老板（21点）$50、醉汉/村民/旅客 $50
  - 欠账时斗地主只能玩底分 1；吧台/商店买不起就买不起，不会白拿
- **主角**：默认男性，名字 **JACK BLACK**（第一天掌柜登记确认，之后可花 **$5** 改名，床头柜钱包面板）
- **丽塔**（老板的女儿，红发开朗女孩）：在大厅帮忙
  - **好感度系统**（剧情暂不做）：商店买 **🌷 花** 或吧台买 **🎂 蛋糕**（各 $2）送她，好感 +1，**一天一次**
  - 有闲谈台词；好感度暂时只涨不看，后续再接剧情
- **随机访客**（每天随机 2 位刷新在酒馆，大厅**可对话 NPC 最多 7 位**）：
  - 🧝 **比利**（精灵治安官，+$5 21点上限）/ 手下 **汤米**、**威尔**（各 +$2）
  - 🧓 **希格**（领主老仆人，+$3）｜ 📮 **马克**（邮差，-$2）｜ 👩🌾 **玛丽**（农妇，-$2）｜ 🐔 **安娜**（养鸡户，-$3）
  - 他们都各有个性闲谈；常驻老板/醉汉/村民/商人/丽塔 5 位不变
- **21点 上桌打牌**：每天第一次进 21点 随机 0~2 位访客**真上桌打牌**（自动下注 $1~3、17 点停牌、与老板结算）——**NPC 可能赢走老板的钱**（玩家今日可赢额度随之减少），也可能输给老板（额度恢复）；老板日赢上限 = 基础 $20 + 上桌 NPC 修正（比利 +$5、汤米/威尔 +$2、希格 +$3、马克/玛丽 -$2、安娜 -$3）
- **德州 多人桌**：每天第一次进德州随机 0~4 位访客上桌（共 2~6 人局），NPC 各自下注/加注/弃牌，摊牌多人比牌、平局平分底池（访客用温和 AI，醉汉仍最激进）
- **斗地主**：满 3 人开（你 + 村民 + 旅客），倍数封顶 ×16
- **户外地图**（大厅大门 → 村口）：
  - 🏞 **小河边**：🎣 **钓鱼小游戏**（抛竿等咬钩、时机收杆；鱼可**卖 $0.5~2 给老板**、**制成标本挂房间墙上**（最多 2 条）或放生；鱼饵 $0.1/竿）；📮 **邮筒寄信**（$0.5，3 天后奶奶回信 +5 心情）；老渔夫闲谈
  - 🌾 **村边农地**：**农业系统**——
    - 👨🌾 **农夫艾尔**（农具摊，农田和酒馆都有）：**买地 $20/块**（最多 6 块）、**买种子 $2/袋**、**雇工 $1/块/天**（只算已播种地块，睡醒扣工钱）、**播种**（需空闲地+种子+雇工，3 天后收成 $7/块）——单块地约 **17 天回本**（长线投资）
    - 👷 **建筑工罗伯特**（工地，农田和酒馆都有）：**盖仓库 $30**（3 天建成）——没有仓库存不住收成只能贱卖；建成后收成自动入仓，可挑时候卖出
    - **🌾 田格可视化（二期）**：农地画出 2×3 共 6 块田格，买一块解锁一块，走近能看"空闲/在长/熟了"
    - **🫧 池塘（二期）**：农地左下角水塘，$0.2 捞一网，泥鳅/草鱼/鲢鱼看手气，可卖可放生
    - 收成/雇工在睡觉跨天时结算（工钱、收成、仓库落成都有事件提示）
  - 🍊 **河西果园**（农地往西过河，二期）：**买果园地 $25/块**（最多 3 块）+ **果苗 $10/袋**，种下 **5 天挂果收 $18/棵**，**不用雇工**（果树自己长）；老园丁闲谈
  - ⛪ **密林小教堂**（村口往密林，二期）：石头搭的生命之神教堂，**祈祷 $1 → 心情 +5**；老牧师讲石头教义与村里传说
  - 🏰 **庄园前**：领主庄园大门，**暂时不可交互**——卫兵驱赶"老爷的地盘，闲人免进"（墙下加了葡萄架远景）
  - 地图主要用于后续剧情与玩法扩展
- **认同度**（村里对你的印象，0~100）：
  - 吧台 **🍻 请客**（请一轮麦酒 $3 / 请顿好酒好菜 $8）提升认同度
  - 达到 30/60/90 解锁 NPC 的专属对话（他们开始跟你说心里话）
  - 后续小事件会增减认同度（系统已预留）
- **一楼大厅**（`WASD`/方向键 移动，`E`/回车 交互）：
  - 🃏 **21点牌桌**（老板坐庄）：下注/保险/分牌/双倍
  - 🂠 **德州牌桌**（醉汉作陪）：底注 $1、四轮下注、单局投入上限 $20
  - 🎴 **UNO 牌桌**（3 位访客作陪）：108 张牌、功能牌齐全；底注 $1 直扣、赢家得 $4（优先当天访客上桌）
  - 🀄 **斗地主桌**（村民·旅客）：叫地主、11 类牌型、炸弹/春天倍数封顶 ×16
  - 🏓 **乒乓球台**（村民应战）：入场 $1，先到 7 分赢，W/S 或触摸控制
  - 🐍 **蛇笼**（贪吃蛇）：入场 $1，吃满 20 个食物过关
  - 🍺 **吧台**：麦酒/黑面包/烤鲈鱼/热汤（花钱换心情）
  - 📒 **账房**（商人）：战绩流水 + **🛒 购置家具**（书桌/书架/衣柜/钱箱/盆栽/挂画/烛台/地毯）
  - NPC 会走动、会随机闲谈
- **退出**：`Esc` 菜单 → 退出酒馆（在房间/大厅均可）

## 🎲 规则（与终端版一致）

| 项 | 规则 |
|---|---|
| 钱包 | $5 起、可负债；整数分存储避免 float 精度问题 |
| 21点 | A=1/11、Blackjack 1.5 倍、保险 2:1、分牌/双倍 |
| 德州 | 1v1 醉汉 AI（加注门槛 0.55/跟注 0.25）、10 种牌型、投入上限 $20 |
| 斗地主 | 1+2 电脑、叫地主、11 类牌型、炸弹×2/春天×2、封顶 ×16 |
| UNO | 108 张牌（红黄蓝绿）；匹配颜色/数字/符号出牌，跳/转/+2/万能/+4；4 人局（优先当天访客），底注 $1、赢家得 $4 |
| 乒乓 | 入场 $1、先到 7 分、W/S 或触摸控制 |
| 贪吃蛇 | 入场 $1、20 食物过关 +$2、速度随长度递增 |
| 时间/心情 | 早晨→中午→晚上；进出游戏 5/5/2 次推进；睡觉到次日早晨；赢钱开心输钱丧 |
| 日赢上限 | 已开放为无限（开关在 progress.js，可随时恢复 $20/$8） |
| 赊账/贷款 | 钱包最低 -$30；商人贷款 $10/$20/$50（日息 5%）；奶奶每 3 天送 $7 零花钱 |
| 对手钱包 | 老板（21点）$50、NPC $50：下注/加注不能超过 |
| 随机访客 | 每天 2 位（共 7 位候选）；大厅可对话 NPC ≤ 7；21点 0~2 位/德州 0~4 位/UNO 3 位真上桌打牌 |
| 主角/丽塔 | 默认名 JACK BLACK（$5 改名）；丽塔好感：花/蛋糕 $2 一天一次 |
| 认同度 | 吧台请客 +；30/60/90 解锁 NPC 专属闲话；后续小事件可增减 |
| 作弊码 | 纸牌游戏下注框输入 `NOTTHISTIME`（进游戏重新输入，且不受赢钱上限约束） |
| 存档 | localStorage `willow_tavern_save`；含钱包/战绩/进度（时间/心情/家具） |
